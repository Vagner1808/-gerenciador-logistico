Sistema em PHP com HTML, CSS, JavaScript e Bootstrap.
Cadastra Produto, Endereço (Origem/Destino), Transportador e gera Frete (1 transportador para vários produtos).
Possui busca de CEP via API ViaCEP, campos dinâmicos em JavaScript e relatório CSV do dia.

Como rodar: Instale o XAMPP, coloque a pasta em C:\xampp\htdocs\gerenciador, ligue o Apache e acesse http://localhost/gerenciador
